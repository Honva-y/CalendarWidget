# 日历小组件（macOS）

一个嵌在桌面上的月历小组件，用 SwiftUI 编写，不需要 Xcode。

## 功能

- 显示整月日历，固定 6 行，大小随窗口缩放；拖动窗口边缘可任意调整大小，也可用预设尺寸
- 中国法定节假日（休）和调休上班（班）：数据来自 [holiday-cn](https://github.com/NateScarlet/holiday-cn)，自动联网更新，并内置 2025–2026 年数据作为离线兜底
- 农历、二十四节气、传统节日和公历节日
- 每周开始日可选，默认周一
- 每行左侧显示周数，标题处显示今天是第几周、一年中的第几天
- 周数规则：ISO 8601（默认）/ 1 月 1 日所在周为第 1 周
- 窗口层级：嵌入桌面 / 普通 / 置顶；外观：跟随系统 / 浅色 / 深色；可调背景不透明度；可锁定位置
- 鼠标滚轮或触控板滑动切换月份；鼠标悬停在日期上可查看详情
- 菜单栏图标和右键菜单中都可以修改设置；支持开机自动启动

## 构建与安装

需要 macOS 14 及以上，并安装 Command Line Tools（`xcode-select --install`）。

```bash
./build.sh            # 生成 build/日历小组件.app
./build.sh --install  # 安装到 ~/Applications 并启动
```

退出方法：点击菜单栏中的日历图标，选择「退出」。
